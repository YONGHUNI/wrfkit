# Documentation source

The rendered documentation lives at:

**https://yonghuni.github.io/wrfkit/**

Start editing with `index.md`. Navigation is defined in the repository-root
`mkdocs.yml`.

Content is organized for different reader needs:

```text
tutorials/      guided learning for a first successful run
how-to/         task-oriented procedures
reference/      commands, file layout, glossary, support status
explanation/    why wrfkit is designed this way
development/    documentation/developer maintenance notes
```

For a local preview:

```bash
pip install -r requirements-docs.txt
mkdocs serve
```
